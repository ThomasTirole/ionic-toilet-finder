# Ionic Toilet Finder

A mobile application built with **Ionic Vue**, **Leaflet**, and **Supabase** to find public toilets, visualize them on a map, and create itineraries.

## Project Structure

- **Frontend**: Ionic Framework (Vue.js)
- **Map**: Leaflet (OpenStreetMap)
- **Backend/Database**: Supabase
- **Device Features**: Capacitor (Geolocation)

## Step-by-Step Implementation Guide

### 1. Project Setup

**Prerequisites**: Node.js installed.

1. **Install Dependencies**:
   ```bash
   npm install leaflet @types/leaflet @supabase/supabase-js @capacitor/geolocation
   ```

2. **Environment Variables**:
   Create a `.env` file in the root directory:
   ```env
   VITE_SUPABASE_URL=your_supabase_url
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```

### 2. Database Setup (Supabase)

1. **Create a new Project** on [Supabase](https://supabase.com).
2. **Go to the SQL Editor** and run the following script to create tables (`toilets`, `profiles`) and insert test data:

   ```sql
   -- Create Toilets Table
   create table toilets (
     id bigint generated by default as identity primary key,
     name text not null,
     address text,
     lat double precision not null,
     lng double precision not null,
     is_accessible boolean default false,
     price numeric,
     description text
   );

   -- Create Profiles Table (for Auth)
   create table profiles (
     id uuid references auth.users not null primary key,
     email text
   );

   -- Enable RLS
   alter table toilets enable row level security;
   create policy "Public read" on toilets for select using (true);

   -- Insert Test Data
   insert into toilets (name, address, lat, lng, is_accessible, price) values
   ('Bar "Le Suisse"', 'Rue du 23-Juin 15', 47.3686, 7.3456, true, null),
   ('Toilettes Publiques', 'Rue des Malvoisins 18', 47.3650, 7.3400, true, 0.00),
   ('Gare CFF', 'Place de la Gare', 47.3700, 7.3500, true, 1.00);
   ```

### 3. Application Logic

- **Map (`MapContainer.vue`)**: initializes Leaflet map, displays markers from the `toilets` data.
- **Drawer (`ToiletDrawer.vue`)**: Lists toilets. Clicking a toilet emits an event to center the map. "GO" button calculates a simple straight-line itinerary.
- **Geolocation**: App requests permission to locate the user on load.

### 4. Running the App

 **Web (Browser)**:
   ```bash
   ionic serve
   ```

 **Mobile (Android/iOS)**:
   ```bash
   ionic cap add android
   ionic cap val
   ionic cap open android
   ```
